# Queen Cassy's Management System

A web-based system for managing the daily operations of Queen Cassy's food business. It covers products and inventory, sales, expenses, employees, attendance, payroll, notifications, and business reports.

## Features

- Manager and owner dashboards
- Product, inventory, and product assignment management
- Sales orders, income, expenses, and capital tracking
- Employee account and attendance management
- Payroll and attendance request handling
- Notifications and business reports

## Requirements

### Software

- A modern web browser such as Chrome, Edge, Firefox, or Safari
- Internet access

### Hardware

The system can be accessed from a computer, tablet, or smartphone with internet access. No special hardware is required.

## Access the Website

Open the live website: [**siomai-b3afe.web.app**](https://siomai-b3afe.web.app/).

## Username and Password

There are no default or demo login credentials documented in this repository. Create an account in Firebase Authentication or use credentials provided by the system owner. To set up the first owner or administrator account, configure the appropriate email in `OWNER_EMAILS` or `ADMIN_EMAILS` and make sure the account exists in Firebase Authentication. Authorized users can create manager and employee accounts in the system.

| Account type | Username / email | Password |
| --- | --- | --- |
| Owner / Administrator | Set by the project owner in Firebase Authentication | Set privately by the account holder |
| Manager / Employee | Created by an authorized user in the system | Set when the account is created |

Do not put actual passwords, service account keys, or other secret credentials in this README or a public repository.
